# Flutter-клиент

Начальный Flutter UI с инициализацией Supabase, регистрацией и входом по email/паролю, первоначальным созданием хозяйства и экраном разделов.

## Настройка подключения к тестовому Supabase

Из папки `app` установите зависимости:

```bash
flutter pub get
```

Передавайте параметры подключения локально через аргументы запуска. Не добавляйте реальные значения ключей в Git:

**Windows PowerShell:**

```powershell
flutter run --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co --dart-define=SUPABASE_PUBLISHABLE_KEY=sb_publishable_YOUR_KEY
```

**macOS / Linux:**

```bash
flutter run --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co --dart-define=SUPABASE_PUBLISHABLE_KEY=sb_publishable_YOUR_KEY
```

Замените значения на Project URL и Publishable key из Supabase Dashboard. Publishable key предназначен для клиентского приложения; безопасность данных обеспечивается RLS и корректными правами в базе. Никогда не передавайте в приложение `service_role` или Secret key.

Без этих параметров приложение запускается в демонстрационном режиме.

## Авторизация и первое хозяйство

- На экране входа можно войти по email и паролю или зарегистрировать отдельную тестовую учётную запись.
- В hosted Supabase подтверждение email обычно включено по умолчанию. После регистрации проверьте почту, подтвердите адрес и затем войдите. Если подтверждение выключено в настройках проекта, Supabase может сразу вернуть активную сессию.
- После первого входа без членства в хозяйстве приложение вызывает RPC `create_organization`. Первый пользователь создаваемого хозяйства получает роль `owner`.
- Если у пользователя несколько хозяйств, отображается экран выбора.
- Выход завершает локальную сессию Supabase.

Официальная документация: [регистрация пользователя](https://supabase.com/docs/reference/dart/auth-signup), [вход по email и паролю](https://supabase.com/docs/reference/dart/auth-signinwithpassword).

## Проверки и запуск

```bash
flutter analyze
flutter test
flutter run
```

Для Android/iOS используйте настроенный эмулятор или устройство. Для desktop предварительно включите поддержку соответствующей платформы в Flutter SDK.

## Ограничения текущего этапа

Экраны авторизации и создания хозяйства добавлены в исходный код, но пока не прошли сборку и runtime-тест. Разделы главного экрана остаются заглушками. Не подключены полноценные хозяйственные формы, Storage, офлайн-БД и синхронизация. Часть операций записи в базе намеренно закрыта миграцией безопасности до реализации транзакционных RPC. Используйте только тестовые данные.
