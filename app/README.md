# Flutter-клиент

Это начальный UI-каркас. Он пока не подключён к Supabase, не содержит авторизации, реальных форм и офлайн-синхронизации.

## Запуск

Из папки `app`:

```bash
flutter pub get
flutter analyze
flutter test
flutter run -d windows
```

Для Android/iOS используйте соответствующий настроенный эмулятор или устройство. Для desktop-платформ предварительно включите поддержку платформы в Flutter SDK.
