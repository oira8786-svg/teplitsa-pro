# Подключение серверных операций ФаёзАгро

После миграций 001–004 открой в репозитории файл `supabase/INSTALL_OPERATIONS.sql`.

Скопируй весь файл целиком, вставь его в SQL Editor тестового проекта Supabase и нажми Run. Скрипт объединяет функции из миграций 005–008, поэтому запускать четыре файла отдельно не нужно.

Скрипт создаёт или заменяет функции и права EXECUTE. Он не удаляет таблицы и существующие записи; его можно безопасно выполнить повторно.

После успешного применения станут доступны серверные операции агрономического журнала, склада, сбора урожая, продаж, оплат, расходов, задач и зарплаты.

Пока не используй реальные данные сотрудников и покупателей: сначала нужно отдельно проверить изоляцию хозяйств, роли, резервные копии и требования к локализации персональных данных в РФ.
